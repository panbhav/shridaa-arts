## ✨ Features
- **Authentic Portfolio**: Features all 27 original handmade Lippan artworks.
- **Centralized Data**: Single source of truth in `data/artworks.json`. Updating price dynamically updates across the entire site.
- **Live Search & Dynamic Category Filtering**: Search by name, motif, or material; filter by category and availability.
- **Dedicated Artwork Detail & Lightbox**: Fullscreen zoom inspection, specifications table, and pre-filled WhatsApp enquiry link with artwork name and price.
- **Secure Studio CMS**: Built-in Node.js / Express backend with JWT authentication and instant 1-click price updates.
- **Responsive & Accessible**: Mobile-first design optimized for all screen sizes (320px to 4K).

## 🚀 Running Locally

```bash

# 2. Start the local server

```

- **Public Website**: `http://localhost:3000`
- **Artworks Gallery**: `http://localhost:3000#artworks`
